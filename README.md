# 📡 Telecom Customer Churn Prediction — End-to-End ML Pipeline

An end-to-end Machine Learning and Business Intelligence solution for predicting customer churn in the telecom industry. Built on the **Databel** dataset, this project features an automated scikit-learn pipeline, resilient data sanitization for messy real-world data, a CLI inference tool, and a **Streamlit** web application.

---

## 📌 Project Overview

Customer churn (customer attrition) is a critical challenge in the telecommunications sector. Acquiring new customers can cost up to 5 times more than retaining existing ones. This project provides an automated machine learning workflow to:

1. **Analyze customer behavioral patterns and demographics** through interactive exploratory data analysis (EDA).
2. **Train and persist a balanced classification model** that identifies high-risk churn customers.
3. **Ingest and sanitize raw, messy Excel/CSV files** (handling missing values, non-numeric artifacts like `'?'`, whitespace, and multi-sheet workbooks).
4. **Deliver actionable churn risk probabilities** and ground-truth validation metrics through a Streamlit dashboard and CLI tool.

## 📊 Dataset & Feature Schema

The primary dataset is derived from the **Databel** telecom customer dataset:

### 1. Target Variable
* **`Churn Label`**: Indicates whether the customer left the telecom service (`Yes` = 1, `No` = 0).

### 2. Excluded Columns (Prevent Leakage & Memorization)
* **Identifiers**: `Customer ID`, `Phone Number` (prevent artificial memorization).
* **Target Leakage Fields**: `Churn Category`, `Churn Reason` (these fields are recorded only *after* a customer has churned).

### 3. Feature Columns (24 Model Features)

| Category | Features |
| :--- | :--- |
| **Numerical (13)** | `Account Length (in months)`, `Local Calls`, `Local Mins`, `Intl Calls`, `Intl Mins`, `Extra International Charges`, `Customer Service Calls`, `Avg Monthly GB Download`, `Extra Data Charges`, `Age`, `Number of Customers in Group`, `Monthly Charge`, `Total Charges` |
| **Categorical (11)** | `Intl Active`, `Intl Plan`, `Unlimited Data Plan`, `State`, `Gender`, `Under 30`, `Senior`, `Group`, `Device Protection & Online Backup`, `Contract Type`, `Payment Method` |

## ⚙️ Machine Learning Pipeline Architecture

The model uses a scikit-learn `Pipeline` composed with `ColumnTransformer`:

```
                       Raw Customer Data (Excel / CSV)
                                      │
                                      ▼
                        [Data Sanitization Layer]
                 • Strips whitespace & normalizes headers
                 • Replaces '?', 'NA', '-', '' with NaN
                 • Coerces numeric features with pd.to_numeric
                 • Aligns feature columns and drops leakage
                                      │
                ┌─────────────────────┴─────────────────────┐
                ▼                                           ▼
      [Numerical Pipeline]                        [Categorical Pipeline]
 1. SimpleImputer(median)                   1. SimpleImputer(most_frequent)
 2. StandardScaler()                        2. OneHotEncoder(handle_unknown='ignore')
                └─────────────────────┬─────────────────────┘
                                      ▼
                      [ColumnTransformer Preprocessor]
                                      │
                                      ▼
             [LogisticRegression(class_weight='balanced', max_iter=2000)]
                                      │
                                      ▼
                   Predictions & Churn Risk Probabilities (%)
```

### Model Performance Metrics (Test Set, 20% Stratified Split)

* **Accuracy**: `~86.5%`
* **ROC-AUC Score**: `~0.945`
* **Recall (Churned Customers)**: `~88.0%` (Prioritizes identifying churners to reduce false negatives)
* **Precision (Churned Customers)**: `~70.0%`
* **F1-Score**: `~0.78`

## 🚀 How to Run the Project

### Option 1: Streamlit Web Dashboard (Recommended)

Launch the interactive web UI:

```bash
streamlit run app.py
```

The app will open automatically in your browser at `http://localhost:8501`.

#### Application Features:
* **🏠 Home Page**: High-level churn KPIs, churn distribution donut chart, churn by contract type, dataset preview, and a one-click **Train / Re-train Model** button.
* **📊 EDA Dashboard**: Interactive categorical churn breakdown charts, distribution boxplots, and dataset summaries.
* **🤖 Predict Page**:
  * Upload any `.xlsx`, `.xls`, or `.csv` file.
  * **Multi-Sheet Detection**: Workbooks like `telecom_churn_raw_eda_test_1500.xlsx` have multiple sheets (`Raw Data`, `Prediction Features Raw`, `README`); the app auto-selects the sheet with the best feature match and lets you toggle sheets from a dropdown.
  * **Automatic Sanitization**: Cleans `'?'` and string artifacts in numeric columns on-the-fly and presents a sanitization audit badge.
  * **Ground Truth Evaluation**: If the uploaded data includes a `Churn Label` column, the app computes test **Accuracy**, **ROC-AUC**, **F1-Score**, and renders a confusion matrix heatmap.
  * **Interactive Risk Distribution & Filter**: Filter customers by risk threshold or churn prediction.
  * **Excel Export**: Download the prediction results as a formatted `.xlsx` spreadsheet.

## 🧹 Automated Raw Data Sanitization Guide

Real-world datasets often arrive with formatting anomalies. This pipeline includes built-in safeguards:

1. **Non-Numeric Artifacts (`'?'`, `'NA'`, whitespace)**:
   * String representations of missing data are converted to `np.nan`.
   * Numeric columns are cast via `pd.to_numeric(errors='coerce')`, preventing `ValueError: Cannot use median strategy with non-numeric data`.
2. **Column Name Discrepancies**:
   * Headers are stripped of leading/trailing spaces and aligned case-insensitively (e.g., `'age'` or `' Age '` maps to `'Age'`).
3. **Missing Features**:
   * If an uploaded file omits some feature columns, they are automatically initialized with `np.nan` and imputed using the training median or mode.
4. **Multi-Sheet Workbooks**:
   * The app inspects sheets, detects the sheet containing customer feature columns, and skips documentation sheets (such as `README`).
