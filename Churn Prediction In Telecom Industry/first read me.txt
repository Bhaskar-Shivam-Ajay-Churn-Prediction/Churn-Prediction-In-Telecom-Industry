First you must create a .venv virtual enviornment which i think you can see inside this folder but it's not running in your PC because directories are different and may be your VS code don't have the libraries which needed....
 
1. first check python version: 
code: 
python --version
in terminal of VS code
if you have then OK 
if you don't have then need to install.


2. Open just go to + in VS Code Terminal and open cmd from that place to terminal and navigate to your extracted project folder:
something like this
code:
cd "C:\Users\Bhaskar\Downloads\churn-prediction-ml-pipeline"


3. Create a Virtual Enviornment under that directory which can run your libraries:
code:
py -3.13 -m venv .venv

4. Activate it
code:
.venv\Scripts\activate

5.Install the project dependencies:
code:
python -m pip install --upgrade pip
pip install -r requirements.txt

6. after that it take some time to install particular libraries which needed, then run eda.py python file, then run train_pipeline.py. if you find any library missing in your virtual enviornment then simply install like: code: .\.venv\Scripts\python.exe -m pip install joblib (only if missing)

7. it generate output 

8. but we need streamlit ui for showing our output in browser or port
